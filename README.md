# guided-mom-app
AI-powered women’s wellness application supporting pregnancy and postpartum care with personalized guidance, symptom tracking, emotional check-ins, and smart health suggestions. Built using Next.js, Firebase (Auth + Firestore), and OpenAI for real-time AI assistance.

Women’s Health & Wellness App
AI-Powered Pregnancy, New Mom, Period & Hormonal Health Companion

⭐ Overview
This application is designed to support women across all major health phases — menstrual care, pregnancy, postpartum baby care, and hormonal wellness. The app works as a personal AI-based guide that provides health suggestions, reminders, and personalized insights based on the user’s current life stage.

🎯 Key Features
🔹 1. User Profile Selection
Women can choose their category:


Menstrual / Period Tracking


Pregnancy Care


New Mother / Baby Care


PCOD / PCOS / Hormonal Health



🔹 2. AI Health Guidance
The app uses AI to:


Analyze user inputs (symptoms, emotions, habits)


Provide personalized health suggestions


Track wellness patterns


Offer actionable guidance based on pregnancy week or menstrual cycle day



🔹 3. Pregnancy Features


Weekly fetal development insights


Symptoms monitoring


Safe exercises and food suggestions


Weight & blood pressure tracking


Appointment reminders


Emergency alert system



🔹 4. New Mom Features


Baby feeding reminders


Breastfeeding tips


Baby sleep cycle guidance


Vaccination reminders


Daily baby-care task checklist



🔹 5. Menstrual & Hormone Health


Period tracking


Cramp & symptom logging


Mood tracking


PCOD/PCOS knowledge center


AI lifestyle recommendations (food, yoga, habits)

🚀 How to Run the Project


Clone the repository
git clone <repo-url>



Install dependencies
npm install



Add your Firebase configuration in firebase.js


Start the development server
npm run dev




📝 How AI Works Here


AI reads user’s current stage (pregnancy/week, menstrual day, symptoms).


Generates personalized responses:


Health tips


Daily routines


Nutrition guidance


Emotional support


Baby care reminders
